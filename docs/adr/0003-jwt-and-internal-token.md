# ADR 0003. JWT для пользователей и внутренний токен для сервисов

## Контекст

Внешние клиенты должны работать с ролями `USER` и `ADMIN`, а вызовы между сервисами не должны требовать пользовательской сессии.

## Решение

`booking-service` выпускает JWT HS256 со сроком жизни 1 час и ролями в claim `roles`. JWT проверяют `booking-service`, `hotel-service` и Gateway. Внутренние эндпойнты дополнительно защищены статическим заголовком `X-Internal-Token`.

## Последствия

- Каждый сервис самостоятельно проверяет токен (defense in depth).
- Внутренние вызовы не зависят от пользовательского токена.
- Секреты по умолчанию подходят только для локального запуска.
