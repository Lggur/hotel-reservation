# ADR 0004. Маршрутизация через Gateway и блокировка внутренних путей

## Контекст

Клиенты должны обращаться к единому адресу, но внутренние эндпойнты нельзя публиковать наружу.

## Решение

Gateway маршрутизирует `/api/auth/**` и `/api/bookings/**` в `booking-service`, а `/api/hotels/**` и `/api/rooms/**` — в `hotel-service` через `lb://` и Eureka. Глобальные фильтры отклоняют внутренние пути (`/internal/**`, `confirm-availability`, `release`) с ответом `404`, проверяют JWT и добавляют `X-Request-Id`.

## Последствия

- Внешний контракт сосредоточен в одном месте.
- Внутренние эндпойнты недоступны через шлюз, но остаются доступны напрямую для сервисов.
- Порядок фильтров важен: блокировка внутренних путей выполняется раньше проверки JWT.
